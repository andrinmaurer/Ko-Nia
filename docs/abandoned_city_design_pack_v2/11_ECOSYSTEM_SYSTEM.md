# Ecosystem System

## Resolved Simulation Level

Target: **Medium-depth ecosystem simulation**

Near the player:
- individual animals
- needs
- territories
- predator / prey behavior
- schedules
- reactions
- group behavior

Far from the player:
- simplified population / habitat simulation

This keeps the world alive without trying to fully simulate thousands of animals at all times.

## Ecosystem Goals
