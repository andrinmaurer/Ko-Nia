# UI / UX

## Resolved UX Principles

- UI should support long relaxing sessions and short 10–15 minute sessions.
- Completion should be clear.
- The game should avoid unnecessary timers and forced interruptions.
- The interface should work well for neurodivergent players without labeling the entire game around that audience.
- The Logbook should be extremely searchable / sortable.
- Discovery feedback should feel satisfying but calm.

## HUD Style

## Discovery Feedback

Recommended style:

No XP explosion.

Instead:
- subtle sound
- organism outline resolves
- `LOGBOOK ENTRY CREATED`
- newly learned field briefly appears

Keep / change: keep

## Map

Resolved:
Locked until 5%.

After unlock, map shows:
- explored terrain
- activated Relay Stations
- discovered landmarks
- custom markers

Should it also show:
- habitats
- previous sightings
- dangerous zones
- weather
- suspected discoveries

Answer: yes

- no punishment for missing timed events
- sortable catalogue
- favorites
- filters
- optional reminders
- calm mode
- no forced daily streaks
- no manipulative retention mechanics
