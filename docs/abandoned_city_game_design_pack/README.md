# Abandoned City Exploration Game — Design Pack

This folder contains the minimum design documents needed to turn the game idea into a concrete development plan.

## Recommended order

1. `01_GAME_VISION.md`
2. `02_CORE_GAMEPLAY.md`
3. `03_WORLD_AND_LORE.md`
4. `04_EXPLORATION_AND_DISCOVERY.md`
5. `05_ART_AND_AUDIO_DIRECTION.md`
6. `06_TECHNICAL_DIRECTION.md`
7. `07_SCOPE_AND_ROADMAP.md`

You do not need to answer every question immediately. Short answers are fine. Unknowns can be marked `TBD`.

Once these are filled in, they can be converted into:
- a full Game Design Document
- a technical architecture
- a browser-engine/tooling recommendation
- a prototype plan
- a content pipeline
- milestone and production roadmap
